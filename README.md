# Hireme-Outsourcing-Client-Dashboard

HireMe Outsourcing Client Portal & Enterprise Dashboard.

## Features
- Company-isolated enterprise client view & staffing management
- Real-time active deployed workforce monitoring
- Monthly timesheet submission with working days, leaves, overtime & performance rating
- Real-time invoice tracking and payment status
- Hiring requisition tracking and candidate profile sign-offs

## Setup & Running Locally
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
